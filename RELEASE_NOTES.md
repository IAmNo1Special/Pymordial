# Pymordial v0.3.1 Release Notes

## 📚 Documentation & Cleanup

This is a minor release focused on documentation improvements and configuration cleanup.

### Changed

*   **README**: Updated project scope to "Extensible Automation Framework" (platform agnostic design).
*   **Configuration**: Removed deprecated `easyocr` section from `configs.yaml` and `pymordial_config.example.yaml`.
*   **Changelog**: Added `CHANGELOG.md` with complete version history (0.1.0 → 0.3.1).

### 📦 Installation

```bash
uv add pymordial==0.3.1
```

## What's New in 0.3.0 (Previous Release)

For the major architectural changes, see [v0.3.0 Release](https://github.com/IAmNo1Special/Pymordial/releases/tag/v0.3.0):

*   Architecture refactor (blueprints, devices)
